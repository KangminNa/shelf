Shelf는 개인 서버 한 대에서 Git 저장소나 Docker 이미지를 컨테이너로 배포하고, 도메인·SSL·CI/CD를 대신 처리하는 셀프호스팅 앱 플랫폼입니다. Shelf runs on one server of your own. It deploys a Git repository or a Docker image as a container and handles the domain, the certificate, and the deploy pipeline for you.

U1

배포Deploy

저장소를 등록하면 그 다음부터는 git push가 배포입니다. Register a repository once. After that, git push is the deploy.

Git이든 이미지든Git or image

저장소를 clone해 docker build하거나, Docker Hub·GHCR의 이미지를 그대로 pull합니다. Clone and docker build, or pull a published image from Docker Hub or GHCR.

push하면 배포Push to deploy

GitHub·GitLab 웹훅을 걸면 지정한 브랜치의 push마다 다시 빌드하고 컨테이너를 교체합니다. Point a GitHub or GitLab webhook at Shelf. Pushes to your branch rebuild and replace the container.

되돌리기Roll back

배포 이력에서 예전 커밋을 고르면 그 시점으로 다시 빌드합니다. 로그도 함께 남습니다. Pick an earlier commit from the deploy history and Shelf rebuilds from it. The log is kept with it.

U2

도메인과 인증서Domains and certificates

리버스 프록시가 내장돼 있습니다. 별도의 nginx 설정 파일은 없습니다. The reverse proxy is built in. There is no nginx config file to write.

도메인 붙이기Attach a domain

앱에 도메인을 적으면 프록시에 자동 등록됩니다. 앱끼리는 컨테이너 이름으로 직접 연결돼 포트를 열 필요가 없습니다. Type a domain into the app and it is registered with the proxy. Apps talk over a shared Docker network, so no host ports need opening.

SSL 자동 갱신SSL that renews itself

Let's Encrypt를 HTTP-01 또는 Cloudflare DNS-01로 발급합니다. 와일드카드도 됩니다. 갱신은 매일 확인합니다. Issues Let's Encrypt certificates over HTTP-01 or Cloudflare DNS-01, wildcards included, and checks for renewal daily.

인증서가 생기면 HTTPS 강제HTTPS enforced on arrival

관리 화면 도메인에 인증서가 생기는 즉시 80은 301로 넘기고 HSTS를 켭니다. 인증서를 지우면 다시 풀립니다. The moment the admin domain has a certificate, port 80 redirects and HSTS turns on. Remove the certificate and it reverts, so you never lock yourself out.

U3

감시와 알림Watching and alerts

앱이 죽었다는 걸 대시보드를 열어봐야 아는 건 감시가 아닙니다. Finding out an app died by opening the dashboard is not monitoring.

서버와 앱의 지표Host and app metrics

호스트 CPU·로드·메모리·디스크 여유와 앱별 CPU·메모리를 대시보드에서 봅니다. 값은 백그라운드 표본이라 화면이 기다리지 않습니다. Host CPU, load, memory and free disk, plus per-app CPU and memory. Sampled in the background, so the page never waits on Docker.

상태가 바뀔 때만Only when something changes

앱이 죽으면 한 번, 돌아오면 한 번 알립니다. 직접 세워둔 앱은 장애로 보지 않습니다. One alert when an app goes down, one when it returns. An app you stopped on purpose is never an incident.

받는 곳은 내가 정함Delivered where you want

웹훅 주소를 등록하면 JSON으로 POST합니다. Discord·Slack 주소도 그대로 쓰고, 시크릿을 넣으면 HMAC 서명이 붙습니다. Register a webhook URL and Shelf POSTs JSON to it — a Discord or Slack URL works as is. Add a secret and the body is HMAC-signed.

U4

설치Install

Docker가 있는 리눅스 서버에서 두 줄이면 뜹니다. Two commands on any Linux box with Docker.

서버에서on your server 
$ git clone https://github.com/KangminNa/shelf && cd shelf
$ docker compose up -d --build

# 관리 화면은 첫 접속에서 계정을 만듭니다.The admin UI asks you to create an account on first visit.
# .env 에 도메인을 적으면 부팅할 때 프록시에 자동 등록됩니다:Put your domain in .env and it is registered with the proxy at boot:
#   ADMIN_DOMAIN=shelf.example.com
#   ACME_EMAIL=you@example.com
U5

아직 못 하는 것What it can't do yet

쓰기 전에 아는 편이 낫습니다. 여기 없는 문제는 대체로 해결돼 있습니다. Better to know before you commit. Problems not listed here are generally handled.

무중단 배포Zero-downtime deploys

배포할 때 컨테이너를 교체하므로 몇 초 끊깁니다. 새 컨테이너를 먼저 띄우고 전환하는 방식은 아직입니다. The container is replaced, so there are a few seconds of downtime. Health-checked cutover is not built yet.

시크릿 저장Secret storage

Git 토큰과 웹훅 시크릿은 data/에 평문으로 있습니다. 그 디렉터리를 지켜야 합니다. Git tokens and webhook secrets sit in data/ in plain text. Guard that directory.

여러 대의 서버More than one server

한 대를 잘 쓰는 도구입니다. 클러스터링이나 오토스케일링은 목표가 아닙니다. This is a tool for running one machine well. Clustering and autoscaling are explicit non-goals.

빌드 로그 실시간Live build logs

배포가 끝난 뒤 전체 로그를 봅니다. 진행 중 스트리밍은 아직입니다. You read the full log once the deploy finishes. Streaming while it runs is not there yet.

DNS 제공자DNS providers

DNS-01 방식은 Cloudflare만 지원합니다. 다른 곳은 HTTP-01을 쓰면 됩니다. DNS-01 works with Cloudflare only. Everywhere else, use HTTP-01.

관리자 권한Admin scope

관리자 계정은 설계상 root와 동급입니다. Docker 소켓을 쥐고 있기 때문입니다. The admin account is root-equivalent by design — it holds the Docker socket.

Shelf — 당신의 서버, 당신의 앱, 당신의 규칙. Shelf — your server, your apps, your rules.
